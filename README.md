## 📖 Learning Resources (a.k.a. My Survival Kit)  

If you're also trying to tame the Rust beast, here are some resources that might save your sanity:  

📚 **Official Docs & Books**  
- [The Rust Book](https://doc.rust-lang.org/book/) – The holy grail of Rust knowledge.  
- [Rust by Example](https://doc.rust-lang.org/rust-by-example/) – Hands-on learning with examples.  
- [Rust Reference](https://doc.rust-lang.org/reference/) – For when you want to go full nerd mode.  

🏋️ **Interactive & Practice**  
- [Rustlings](https://github.com/rust-lang/rustlings) – Fix tiny broken programs & learn Rust!  
- [Exercism Rust Track](https://exercism.org/tracks/rust) – Practice with real challenges.  
- [LeetCode Rust](https://leetcode.com/problemset/all/?lang=rust) – If you love suffering (a.k.a. coding challenges).  

🎥 **Videos & Tutorials**  
- [Let’s Get Rusty (YouTube)](https://www.youtube.com/c/Let'sGetRusty) – Rust explained like you’re 5.  
- [No Boilerplate (YouTube)](https://www.youtube.com/c/NoBoilerplate) – Clean, concise Rust tutorials.  
- [Rust Crash Course (Traversy Media)](https://youtu.be/zF34dRivLOw) – Learn Rust in one sitting.  

💬 **Communities & Help**  
- [Rust Users Forum](https://users.rust-lang.org/) – Ask questions, get answers.  
- [Rust Discord](https://discord.gg/rust-lang) – Hang out with Rustaceans.  
- [r/rust (Reddit)](https://www.reddit.com/r/rust/) – News, memes, and discussions.
